# Source of the ig-* skills

The thirteen `ig-*` skills in this folder come from
https://github.com/Jakeschincariol/instagram-agent-skill (commit d03c56b),
by Jake Schincariol, MIT license (see `ig-LICENSE-MIT.txt`).

Reviewed before install: the five Python tools make no network calls, run no
commands and read no credentials; the skills only write copy-ready text and do
not post or log in to Instagram. Voice file: `.claude/instagram/voice.md`.
